# Paralympics Medal Analysis Dashboard (Power BI)

## Project Overview
This project presents an interactive Power BI dashboard that analyzes Paralympic Games medal performance from 1960 to 2018.
The dashboard provides insights into medal distribution, top-performing nations, sports performance, continent-wise participation, and historical medal trends.
---

## Objectives
* Analyze Paralympic medal standings across editions.
* Identify top-performing countries.
* Compare Gold, Silver, and Bronze medal distributions.
* Explore sport-wise medal achievements.
* Understand continent-level participation and performance.
* Track historical medal trends over time.
---

## Dashboard Features
### KPI Cards
* Total Gold Medals
* Total Medals
* Total Nations Competed
* Total Editions

### Country Analysis
* Top 10 Nations by Gold Medals
* Nation-wise Medal Performance

### Medal Analysis
* Gold, Silver, and Bronze Split
* Medal Distribution Trends

### Sports Analysis
* Sport-wise Medal Counts
* Summer vs Winter Paralympic Performance

### Geographic Insights
* Average Medals by Continent
* Regional Participation Analysis

### Trend Analysis
* Gold Medal Trends by Edition
* Historical Performance Tracking

## Key Insights
* 15,722 Total Medals analyzed.
* 5,740 Gold Medals awarded.
* 22 Paralympic Editions covered.
* United States leads in total Gold Medals.
* Athletics contributes the highest medal count among sports.
* Strong participation from Europe and the Americas.
